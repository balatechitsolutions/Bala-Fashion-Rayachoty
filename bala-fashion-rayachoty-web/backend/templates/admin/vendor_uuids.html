Vendor Owner UUIDs

Required workflow: the vendor must first register or sign in on the website using the vendor's email. Find that email in the existing Supabase Auth users list below, copy its Auth UUID, and paste it into the Owner ID field when creating the vendor. Vendor creation is rejected if the UUID is missing, invalid, or does not belong to an existing eligible Supabase Auth user. This page does not create login accounts.

Only Django superusers can link an owner or use this page to manage owner UUIDs.
